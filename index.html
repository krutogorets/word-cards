Импорт слов

Выберите любой .json файл со списком слов — имя файла не важно. Новые слова добавятся к текущей базе, совпадения будут пропущены.

  • Содержимое — JSON-список объектов вида { "en": "apple", "ru": "яблоко" }.
  • Пустые и неполные записи пропускаются.
  • Слова с одинаковым английским и русским значением не дублируются.
