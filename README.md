# Word Cards

Приложение для тренировки английских слов по карточкам. Устанавливается на телефон
как обычное приложение, открывается с домашнего экрана и работает без интернета.

### 👉 Открыть и установить: <https://krutogorets.github.io/word-cards/>

---

## Что умеет

- Два направления перевода: **Английский → Русский** и **Русский → Английский**.
- Стопки по 200 слов — приложение собирает их само из вашей базы.
- Случайный режим: до 200 слов из всей базы, каждый запуск — новый набор.
- Карточка: слово крупно, перевод появляется через 6 секунд или сразу по нажатию.
- Листание в обе стороны: стрелки внизу экрана и свайп влево/вправо.
- Возврат к пройденным словам — карточка открывается в том же виде, в котором вы её оставили.
- Озвучивание английского слова голосом устройства.
- Импорт слов из файла `.json` — база пополняется, дубликаты пропускаются.
- Полная очистка базы слов.
- Всё хранится только на телефоне: без аккаунтов, без сети, без аналитики.

В комплекте уже есть **100 слов** — можно начинать сразу.

## Установка на Android

Интернет нужен только для установки. Дальше приложение работает офлайн.

1. Откройте <https://krutogorets.github.io/word-cards/> в **Chrome**.
2. Дождитесь загрузки страницы (пара секунд).
3. Меню Chrome **⋮** → **«Установить приложение»** → **«Установить»**.
   В некоторых прошивках пункт называется **«Добавить на главный экран»**.
4. На домашнем экране появится иконка Word Cards.

Открывайте приложение с иконки — оно запустится без браузерных панелей и без интернета.

**Если пункта установки нет:** обновите страницу, прокрутите её и подождите несколько
секунд — Chrome показывает предложение установки не сразу. Как запасной вариант:
меню **⋮** → **«Добавить на главный экран»**.

### iPhone / iPad

Откройте ссылку в **Safari** → кнопка **«Поделиться»** → **«На экран Домой»**.
После первого открытия приложение работает офлайн.

## Как заниматься

1. На стартовом экране выберите направление перевода и стопку (или «Случайный режим»).
2. Нажмите **«Начать»**.
3. Смотрите на слово: перевод появится сам через 6 секунд или сразу по нажатию.
4. Дальше — любым удобным способом:
   - **нажатие на карточку**: первое показывает перевод, второе открывает следующее слово;
   - **стрелка вправо** или **свайп влево** — следующее слово;
   - **стрелка влево** или **свайп вправо** — предыдущее слово (на первом слове стрелка
     влево неактивна).
5. Кнопка с динамиком озвучивает английское слово. В режиме «Русский → Английский»
   она появляется только после раскрытия карточки, чтобы не подсказывать ответ.
6. Когда слова закончатся — **«Пройти ещё раз»** или **«Выбрать другой режим»**.

Сверху видно, какая это карточка: например, «5 / 200».

## Как добавить свои слова

1. Подготовьте файл `.json` со списком слов (формат ниже) и положите его на телефон —
   скачайте из облака или мессенджера, перекиньте по кабелю.
2. В приложении нажмите **«Импорт слов из файла»**.
3. Нажмите **«Выбрать .json файл»** и укажите файл.
4. Появится отчёт: сколько слов добавлено, сколько пропущено как дубликаты или
   некорректные записи, сколько всего слов в базе.
5. Вернитесь на стартовый экран — стопки пересчитаются автоматически.

**Имя файла любое** — важно только содержимое. Пример на 200 слов можно скачать прямо
из приложения: кнопка **«Скачать пример words.json (200 слов)»** на экране импорта.

### Формат файла

```json
[
  { "en": "apple", "ru": "яблоко" },
  { "en": "dog", "ru": "собака" }
]
```

Правила:

- порядок слов в файле — это порядок слов в стопках;
- у каждой записи должны быть заполнены `en` и `ru`;
- лишние поля не мешают;
- слова с одинаковой парой «английское + русское» не дублируются;
- если файл битый, это не список или в нём нет ни одного корректного слова — приложение
  покажет понятную ошибку и не тронет текущую базу.

---

## Очистка базы слов

На стартовом экране нажмите **«Очистить базу слов»** и подтвердите.

Удаляются все слова, включая стартовые 100. Вернуть их можно только импортом —
например, скачав пример файла на экране импорта. Действие необратимо.

---

## Приватность

Слова, настройки и прогресс хранятся только на вашем телефоне. Приложение не отправляет
данные в сеть, не требует аккаунта и не собирает статистику. Интернет нужен только для
первой установки и обновлений.

---

## Если что-то не так

- **После обновления открывается старая версия.** Закройте приложение полностью
  (смахните из списка недавних) и откройте снова.
- **Нет кнопки озвучивания.** На устройстве нет английского голоса — остальное
  приложение работает как обычно.
- **Слова пропали.** База хранится в браузере телефона: после очистки данных браузера
  или переустановки приложения её нужно импортировать заново.
