# Word Cards

Офлайн-приложение для тренировки английских слов по карточкам. Работает на телефоне
как обычное приложение: открывается с домашнего экрана, без интернета и без сервера.

---

## Что умеет

- Два направления перевода: **Английский → Русский** и **Русский → Английский**.
- Стопки по 200 слов, собранные автоматически из локальной базы.
- Случайный режим: до 200 уникальных слов из всей базы, каждый запуск — новый набор.
- Карточка: слово крупно, перевод появляется через 6 секунд или сразу по нажатию.
- Листание карточек в обе стороны: стрелки внизу экрана и свайп влево/вправо.
- Нажатие на карточку: первое показывает перевод, второе открывает следующее слово.
- Озвучивание английского слова системным голосом устройства.
- Импорт слов из любого `.json` файла со списком слов (слияние с текущей базой, дубликаты пропускаются).
- Полная очистка базы слов с подтверждением.
- Всё хранится только на телефоне. Никаких аккаунтов, сети и аналитики.

В комплекте уже есть **100 слов** — можно начать сразу. Файл `words.json` содержит
ещё **200 слов** для проверки импорта: после него в базе будет 300 слов и две стопки.

---

## Как открыть на компьютере

```bash
node server.js
```

Откройте <http://localhost:8080>. Тесты: `npm test`.

## Как установить на Android

Приложению нужен «защищённый контекст» (HTTPS или `localhost`) — это требование Chrome
к установке PWA и офлайн-кешу. После установки интернет не нужен вообще.

### Вариант 1. Кабель + adb (без интернета)

1. Скачайте [platform-tools](https://developer.android.com/tools/releases/platform-tools) и
   распакуйте в любую папку.
2. На телефоне включите «Для разработчиков» → «Отладка по USB», подключите кабель,
   подтвердите запрос на компьютере.
3. Запустите сервер: `node server.js`.
4. В той же папке с platform-tools выполните:

   ```bash
   adb reverse tcp:8080 tcp:8080
   ```

5. На телефоне откройте <http://localhost:8080> в Chrome.
6. Меню Chrome (⋮) → **Установить приложение** → «Установить».

После установки кабель можно отключать: приложение откроется из своего кеша.

### Вариант 2. HTTPS-туннель (без кабеля, нужен интернет на время установки)

1. Запустите сервер: `node server.js`.
2. Поднимите временный HTTPS-туннель к порту 8080, например:

   ```bash
   npx cloudflared tunnel --url http://localhost:8080
   ```

   (подойдёт и `ngrok http 8080` — нужен аккаунт).
3. Откройте выданную ссылку `https://…` на телефоне в Chrome.
4. Меню Chrome (⋮) → **Установить приложение**.

Ссылка живёт только на время туннеля — после установки она больше не нужна,
приложение работает офлайн.

### Вариант 3. Просто посмотреть (без установки)

`http://<IP-компьютера>:8080` в локальной сети. Всё работает, но без установки и без
офлайн-режима: Chrome не даёт service worker на обычном HTTP.

## Как импортировать слова

1. Положите файл со словами на телефон (скачайте из облака/мессенджера или
   перекиньте по кабелю). Имя файла любое — важно содержимое: JSON-список слов.
2. В приложении на стартовом экране нажмите **«Импорт слов из файла»**.
3. Нажмите **«Выбрать .json файл»** и укажите файл в системном проводнике.
4. Появится отчёт: сколько добавлено, сколько пропущено дубликатов и некорректных
   записей, сколько слов всего в базе.
5. Вернитесь назад — стопки пересчитаются автоматически.

Пример файла можно скачать прямо из приложения на экране импорта
(кнопка «Скачать пример words.json (200 слов)») — это тот же `words.json`, что лежит
в папке проекта.

### Формат файла со словами

Массив объектов с полями `en` и `ru`:

```json
[
  { "en": "apple", "ru": "яблоко" },
  { "en": "dog", "ru": "собака" }
]
```

Правила:

- порядок слов в файле = порядок добавления в базу (и порядок слов в стопках);
- пустые или неполные записи пропускаются и считаются в отчёте;
- лишние поля игнорируются;
- запись с уже существующей парой «английское + русское» пропускается как дубликат;
- если файл битый, это не массив или в нём нет ни одного корректного слова —
  показывается понятная ошибка, база не меняется.

## Как начать обучение

1. Выберите направление перевода.
2. Выберите стопку (или «Случайный режим»).
3. Нажмите **«Начать»**.
4. Смотрите на слово: перевод появится через 6 секунд или сразу по нажатию на карточку.
5. **Стрелка вправо** или свайп влево — следующая карточка, **стрелка влево** или свайп
   вправо — предыдущая. Возврат показывает слово в том состоянии, в котором вы его
   оставили. На первом слове стрелка влево неактивна.
6. **Нажатие на карточку**: скрытая карточка раскрывает перевод, раскрытая открывает
   следующее слово. Кнопка с динамиком озвучивает английское слово.
7. В конце — «Пройти ещё раз» или «Выбрать другой режим».

В режиме «Русский → Английский» кнопка озвучивания появляется только после раскрытия
карточки, чтобы не подсказывать ответ.

## Как очистить базу слов

На стартовом экране нажмите **«Очистить базу слов»** и подтвердите. Будут удалены все
слова, включая стартовые; вернуть их можно только повторным импортом (пример —
кнопка «Скачать пример words.json» на экране импорта).

## Структура проекта

```
index.html            разметка экранов
styles.css            оформление (светлая и тёмная темы)
app.js               экраны, таймер карточки, свайп, импорт, очистка, озвучка
core.js              чистая логика: разбор файла, слияние, стопки, сессии
session.js           состояние сессии: раскрытие карточек, переходы вперёд-назад, свайп
seed-words.js        стартовая база на 100 слов
words.json           пример файла для импорта (200 слов)
sw.js                service worker: офлайн-кеш
manifest.webmanifest  описание PWA
icons/               иконки приложения
server.js            локальный статический сервер (только для запуска/установки)
tests/               автотесты логики и данных
tools/make-icons.js  генератор иконок
```

## Технические детали

- Данные лежат в `localStorage` под ключом `word-cards.words.v1`.
- При первом запуске база заполняется 100 словами из `seed-words.js`; при повторных
  запусках используется сохранённая база. Очистка записывает пустой массив, поэтому
  стартовые слова повторно не подставляются.
- Офлайн-кеш описан в `sw.js` (`CACHE = 'word-cards-v3'`). Если меняете файлы
  приложения — поднимите номер версии в `CACHE`, иначе телефон продолжит открывать
  старую версию из кеша.
- Состояние сессии живёт в `session.js`: каждая карточка помнит, раскрыта ли она, а
  функции возвращают новую сессию, не меняя исходную. Поэтому возврат назад показывает
  слово в том состоянии, в котором его оставили.
- Таймер карточки привязан к её номеру: при переходе стрелками или свайпом старый
  таймер отменяется, поэтому он не может раскрыть следующую карточку.
- Свайп засчитывается при горизонтальном движении от 48 px, не длиннее 700 мс и не
  больше 1.4× по вертикали; после свайпа нажатие не считается тапом.
- Если озвучка недоступна или английского голоса нет, приложение не падает:
  кнопка остаётся рабочей и пробует синтез с `lang="en-US"`.

## Тесты

```bash
npm test
```

44 теста: разбор и валидация файла со словами, слияние с дубликатами, нарезка на стопки
(200/201/450 слов), сборка стопки и случайной сессии, отсутствие повторов,
неизменность исходных данных, целостность стартовых 100 слов и примера на 200,
состояние сессии (раскрытие, переходы вперёд-назад, тап-цикл, распознавание свайпа).
